Reasons from the rule

    Ease is fixed at 1. A higher score moves this card earlier in the queue; the number is not a probability.

    How priority is calculated

    Recent misses raise a card’s priority. Showing it earlier in the same session lowers its priority, leaving room for other cards. The controls show how each input changes the score.

    Checking
    submitted results.

    The public helper checks answers and timing in a submitted result. It relies on the caller to supply trusted expected answers.

    Compare player IDs

    The helper compares supplied selected and expected player IDs. The caller must provide a trusted expected answer; this function does not authenticate users or fetch an answer key.

    Reject or flag for review
