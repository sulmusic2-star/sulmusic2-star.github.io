SquadBrain

A sports roster learning app for iPhone and iPad.

App StorePublic code

What the public examples show

The full application source is private. The repository contains selected TypeScript examples of session state, ranking, practice selection, matchmaking and submitted-result checks.

Check submitted results

The result validator recomputes correctness from player identifiers and reports inconsistent answer counts, repeated prompts and suspicious timing.

Make selection rules explicit

The practice module calculates practice priority. The matching module uses explicit criteria to select opponents.

Separate rules from screens

The public modules can be run and tested separately. The decision records explain the choices behind result checks, practice and same-team matching.

The application stack described in the repository is React Native, Expo, TypeScript and Firebase. The public examples cover particular rules; their tests do not establish the quality of the entire app, its live services or user outcomes.
