Lasting Ground

Property research with official records and their sources in view.

Public searchPublic code

The problem

Property records sit in separate federal, state and municipal systems. A useful research workflow needs to retain which record supports an answer, when it was checked and what remains unknown.

What the public examples show

The repository contains synthetic Python examples of source validation, evidence scoring and report composition. The full application and its source-acquisition system are private.

Keep incomplete evidence visible

The source validator distinguishes validated, caution and missing states. It returns warnings for missing review dates and unsupported claims.

Assemble reports from structured results

The packet composer builds sections from validation output. A separate language helper constrains summaries when the evidence is incomplete.

Make the rules inspectable

The example inputs, implementation, tests and decision records are available together. Readers can follow the source of a result and run the public examples locally.

These examples demonstrate particular validation and report rules. They do not establish live-source accuracy, geographic coverage, commercial outcomes or production readiness. This work provides informational context and does not replace official or professional determinations.
