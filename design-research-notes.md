# Portfolio design notes

The portfolio puts Lasting Ground first, followed by SquadBrain and selected code. GroundTruth-Geo is a supporting evaluation study.

- Show product images with captions explaining what they depict.
- Label fictional records and archived government responses.
- Link directly to the relevant code, tests and report examples.
- Keep missing information and access requirements visible beside the result.
- Use the Boston building model to let visitors select a building and open its city record. It is a separate study, not a survey or a live Lasting Ground feature.
- Keep plan view, keyboard controls and direct links available alongside the 3D view.
- Use readable type and test the same controls on narrow screens.

The current implementation is described in [DESIGN.md](DESIGN.md). Earlier design iterations remain in Git history.
